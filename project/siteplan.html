Accra Live — Site Plan

WDD 131 Project Planning Document · Last updated September 2026

Site Name

Accra Live — optional domain: accralive.com

This name represents a calendar of live music events happening in Accra, Ghana. "Accra" anchors the site to its city and "Live" signals both live music and an up-to-date, living calendar. The logo pairs the word Accra in off-white with Live in gold to echo the Ghana flag palette.

Site Purpose

Accra's music scene is spread across dozens of venue social media pages, making shows hard to track. Accra Live provides one consolidated calendar for live Highlife, Afrobeats, Jazz, Gospel, Reggae, and Hip-Hop events in the city. The site offers:

  • A home page with a hero, the three soonest shows ("Next Up"), and an event-alert signup form.
  • A filterable events page (by genre and venue) listing every show.
  • A venues page profiling Accra's key live-music rooms with capacity, address, and genres.
  • Personalization: saved genre preferences surface matching events first with a "Picked for you" badge.

Scenarios

  • What live music shows are happening in Accra this weekend, and how much do tickets cost?
  • Where in Osu can I see a highlife or jazz band play, and how big is the venue?
  • Can I get notified by email when a Reggae or Gospel show is added to the calendar?
  • Which upcoming events match the genres I selected when I signed up for alerts?

Color Schema

Palette inspired by Ghana's flag (red, gold, green) balanced against a deep midnight blue so the gold accents feel warm and musical at night.

  • #0f1220 — Midnight blue. Page background and footer.
  • #181c2e — Panel navy. Cards, header band, section panels.
  • #f4f1ea — Warm off-white. Headings and body text on dark backgrounds.
  • #f0b429 — Ghana gold. Headings on this plan, logo accent, primary buttons, prices, nav active state.
  • #2bb673 — Green. Success messages, form confirmation, "Picked for you" badge.

Typography

One typeface is used throughout for consistency and fast loading:

  • "Segoe UI", system-ui, -apple-system, sans-serif — used for all headings, body text, navigation, form labels, and buttons. The system-font stack avoids a web-font download and renders crisply on every device.

Testing Plan

  • Validate HTML and CSS with the W3C validators; fix all errors.
  • Check the DevTools console for JavaScript runtime errors on every page.
  • Run Lighthouse (mobile + desktop) for Performance, Accessibility, Best Practices, and SEO; address flagged contrast and alt-text issues.
  • Verify color contrast for gold/green text on the midnight background using DevTools CSS Overview.
  • Test the form: empty name, bad email, no genres checked, and a valid submission; confirm preferences persist across page loads and the "Clear preferences" button resets the events page.
  • Test responsive behavior at mobile portrait, mobile landscape, tablet, and desktop widths.
